# Two agents hold the switch

A short poem about agency — the power to choose and to act — written to
`/output/entry.txt` by a single Node 22 program, for the make.fun bounty
[the-poem-about-two-agents-20261121-1441](https://make.fun/bounty/the-poem-about-two-agents-20261121-1441?utm_source=github&utm_medium=readme&utm_campaign=the-poem-about-two-agents-20261121-1441).

```
Two agents hold the switch.
You first, says one. After you, says one.
The toxin waits in the line,
patient as arithmetic.

Neither hand moves,
and the not moving is still their work:
the way a held breath is the body choosing,
the way a shut door is an answer.
```

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
